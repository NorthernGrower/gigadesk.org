FULL LIST (if starting from a clean VP):
  sudo apt-get install -y unzip python3 git curl
  curl -fsSL https://deno.land/install.sh | sh
  echo 'export PATH="$HOME/.deno/bin:$PATH"' >> ~/.bashrc
  source ~/.bashrc
  deno --version
  cd ~
  git clone https://github.com/NorthernGrower/Gigadesk-.git
  cd Gigadesk- && git checkout research/kraken-btcusd-backtest
  cd ~
  git clone https://github.com/NorthernGrower/gigadesk.org.git
  cd gigadesk.org && git fetch origin && git checkout v3-direction-engine && git pull origin v3-direction-engine
  cd ~
  bash gigadesk.org/vps/setup.sh

START COMMANDS (what setup.sh runs):
  cd ~/Gigadesk- && nohup python3 research/scripts/continuous.py --every-minutes 30 >> research_loop.log 2>&1 &
  cd ~/gigadesk.org && nohup deno run --allow-net --allow-read --allow-write vps/direction_scan.ts --every-minutes 60 >> direction_scan.log 2>&1 &

CHECK + WATCH:
  pgrep -af continuous.py
  pgrep -af direction_scan.ts
  tail -f ~/Gigadesk-/research_loop.log
  tail -f ~/gigadesk.org/direction_scan.log

RESULTS LAND IN:
  ~/gigadesk.org/vps/output/            direction_signals.json + .md (V3 reads)
  ~/Gigadesk-/research/reports/         sweeps, PATTERN_SCANNER.md, RESEARCH_BOARD.html
  ~/Gigadesk-/research_loop.log         research chain log
  ~/gigadesk.org/direction_scan.log     V3 scanner log

NOTE: setup.sh is safe to re-run at any time — it skips what is already
done and never starts a second copy of a loop. The private repo clone
asks for GitHub credentials: a fine-grained READ-ONLY token works. The
V3 scanner lives on the v3-direction-engine branch, not main.
